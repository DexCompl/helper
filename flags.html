DexCompl

Флаги для регионов

Как использовать:
allow — разрешить, deny — запретить.
Пример: /rg f [Название рг] pvp deny — отключил ПВП в регионе.
1. Базовые флаги
build Включить или выключить разрешение ВСЕМ игрокам строить и ломать в регионе. allow / deny
use Использование механизмов (дверей, кнопок, рычагов и т.д.). allow / deny
interact Убивать мобов и взаимодействовать с некоторыми предметами (двери, нажимные плиты). allow / deny
chest-access Доступ к сундукам и прочим блокам, в которые кладутся вещи. allow / deny
pvp Разрешить или запретить PvP в регионе. allow / deny
invincible Бессмертие в регионе. allow / deny
fall-damage Урон от падения. allow / deny
item-drop Выбрасывание вещей. allow / deny
exp-drops Сбор опыта. allow / deny
2. Защита и Взрывы
mob-damage Урон от мобов. allow / deny
creeper-explosion Взрыв криперов. allow / deny
tnt Взрыв динамита. allow / deny
other-explosion Другие виды взрывов. allow / deny
ghast-fireball Взрывы от фаерболов гастов. allow / deny
entity-item-frame-destroy Ломать рамки. allow / deny
entity-painting-destroy Ломать картины. allow / deny
enderdragon-block-damage Урон блокам от дракона Эндера. allow / deny
lighter Использование зажигалки. allow / deny
fire-spread Распространение огня. allow / deny
3. Мобы и Животные
mob-spawning Спавн мобов. allow / deny
deny-spawn Запретить спавнится перечисленным мобам. моб, моб1, моб2
damage-animals Урон животным. allow / deny
4. Механики и Блоки
enderman-grief Кража блоков эндерменом. allow / deny
enderpearl Использование ока эндера. allow / deny
water-flow Растекание воды. allow / deny
lava-flow Растекание лавы. allow / deny
pistons Использование поршней. allow / deny
leaf-decay Опадение листвы. allow / deny
grass-growth Обрастание грязи травой. allow / deny
vine-growth Распространение лиан. allow / deny
ice-form Замерзание воды. allow / deny
ice-melt Таяние льда. allow / deny
5. Время, Погода и Телепортация
time-lock Смещение времени. число (-24000-24000)
weather-lock Установить погоду в регионе. clear / rain
lightning Удар молнии. allow / deny
teleport Место для телепорта в регион. x y z
spawn Место спавна в регионе. x y z
6. Чат, Команды и Границы
entry Вход в регион. allow / deny
entry-deny-message Сообщение игроку о запрете вхождения в регион. «текст»
greeting Сообщение при входе в регион (можно использовать %name%, чтобы выводился ник игрока). текст
farewell Сообщение при выходе из региона. текст
send-chat Возможность писать в чат. allow / deny
receive-chat Возможность читать чат. allow / deny
blocked-cmds Блокировать команды в регионе (без слэша, если он не двойной). команда, команда1
allowed-cmds Запретить все команды, кроме указанных. команда, команда1
exit Выход из региона. allow / deny
exit-deny-message Сообщение игроку о запрете выхода из региона. текст
game-mode Установить игровой режим в регионе. creative / survival / adventure
7. Прочие флаги
furniture-place Разрешить/Запретить ставить мебель в регионе. allow / deny
magicwand Разрешить/Запретить использование магической палки в регионе. true / false
vehicle-place Размещение транспорта (лодок, вагонеток) в регионе. allow / deny
vehicle-destroy Дроп транспортных блоков. allow / deny
ride Разрешить/запретить использовать транспорт в регионе. allow / deny
heal-delay / heal-amount Скорость исцеления / Мощность исцеления (2 — одно сердце). секунды / число
feed-delay / feed-amount Периодичность насыщения / Сколько единиц сытости восстанавливать. секунды / число
price Цена на регион. число
